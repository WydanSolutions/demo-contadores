# Demostración · Sistema de gestión para estudios contables

Demostración de un sistema de gestión para contadores y estudios contables,
desarrollado por **Wydan Solutions**.

La marca que se ve en pantalla es la del **Estudio Contable W. Machado**, usada
como ejemplo. Cada página se arma a medida del cliente: su nombre, su logo y
las secciones que use de verdad.

- **Todos los datos son inventados.** No hay información real de ningún cliente.
- Funciona por completo en el navegador: no hay servidor ni base de datos.
- Contraseña de la demostración: `1234`.

Cada persona que abre la página trabaja con su propia copia de los datos de ejemplo,
guardada solo en su navegador.
